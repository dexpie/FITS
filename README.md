# FITS — UC-05 Lapor Hilang

Halaman contoh dibuat dengan Next.js (React), TypeScript, dan CSS. Belum menggunakan database; data hanya ada selama halaman dibuka.

Jalankan `npm install`, lalu `npm run dev` dan buka http://localhost:3000. Untuk tugas ini, screenshot halaman dan file `app/page.tsx` serta `app/style.css`. Next.js memakai file `app/page.tsx` sebagai halaman dan rute `/`, sehingga tidak memakai `web.php`.

Halaman contoh lainnya: `/uc02` (login), `/uc08` (laporan saya), `/uc12` (barang temuan), dan `/uc16` (halaman petugas). Masing-masing memakai data contoh dan belum terhubung ke backend.
